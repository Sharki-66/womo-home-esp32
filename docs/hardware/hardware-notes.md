# Hardware Documentation

This folder collects schematics, PCB exports, BOMs, and other project-specific hardware notes.

- Commit editable sources (KiCad/Altium projects, CSV BOMs, Markdown notes).
- Keep vendor datasheets in `datasheets/`; they stay local thanks to the `.gitignore` rule.
- Export PDFs or images of schematics if you want quick reference without the CAD tools.
