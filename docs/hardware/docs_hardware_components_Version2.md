## 💡 Spar-Tipps

### AliExpress statt Amazon
```
Beispiel:
BME280: Amazon €8 → AliExpress €2,50
INA226: Amazon €6 → AliExpress €1,50
PCA9548A: Amazon €5 → AliExpress €1

Ersparnis: ~€50
Nachteil: 2-4 Wochen Lieferzeit
```

### Sammelbestellung
```
✅ Mehrere Sensoren auf einmal kaufen
✅ Versandkosten sparen
✅ Ersatzteile gleich mit bestellen
```

### Open-Source Alternativen
```
✅ Gehäuse selbst 3D-Drucken (Thingiverse)
✅ PCB-Design selbst machen (KiCAD)
✅ Display-Halterung selbst bauen
```
